# WI Film Tax Credits

Landing page for Wisconsin's new (2026) Film Production Tax Credit consulting service.
Primary goal: lead capture / contact.

Built with the same lightweight framework as `iltaxcredits-website` — Vite + plain HTML + a single `styles.css`.

## Develop
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Output is in `dist/`.

## Program facts

Verified August 2026 against
[Film Wisconsin](https://industry.travelwisconsin.com/about-us/film-wisconsin/film-wisconsin-application).

- **30%** Film Production Services Credit on qualified Wisconsin wages and spending
  (refundable and nonrefundable components; the certificate may be used, sold, or transferred)
- **100%** income/franchise tax credit for qualifying Wisconsin sales and use taxes paid
- **$1M** cap per applicant, per fiscal year
- **$5M** statewide allocation each fiscal year
- Minimum threshold is **W-2 salary and wages**, not total spend: $100,000 for projects
  30 minutes or longer, $50,000 for shorter works
- Retroactive to expenditures on/after Jan 1, 2026
- Administered by Film Wisconsin (WI Dept of Tourism); program and office launched Feb 17, 2026
